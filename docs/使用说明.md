## 1. 安装与启动

1. 运行安装程序，按提示完成安装。
2. 启动 vitoice。首次进入时媒体库为空，需先添加媒体目录（见第 3 节）。
3. 界面分为三大模块：**媒体**（浏览与播放）、**管理**（媒体库与文件操作）、**资源库**（收藏与智能文件夹）。

## 2. 首次设置

进入「设置」（顶部右侧齿轮按钮）：

| 设置项 | 用途 | 获取方式 |
|---|---|---|
| TMDB API key | 电影 / 剧集元数据刮削（标题、年份、简介、海报） | [themovie db](https://www.themoviedb.org/) 申请 |
| AI 服务地址 / key / 模型 | 自动打标、智能分类 | 任选 OpenAI 兼容接口 |
| 数据目录 | 生产数据库与缓存存放位置 | 默认 `~/.vitoice/`，可自定义 |

> 明文密钥只保存在**本地数据库**中，不会写入代码仓库。

## 3. 添加与管理媒体库

### 添加目录
- 「管理 → 媒体库 → 添加目录」，选择本地文件夹（支持挂载盘、NAS）。
- 添加后会自动建索引：扫描文件、提取时长与分辨率、生成缩略图。

### 四种视图
主页顶部可切换 **网格 / 列表 / 紧凑** 三种视图；左栏按「全部媒体 / 继续观看 / 智能文件夹 / 标签 / 类型」导航。

### 筛选
顶部筛选栏支持按 **题材、地区、年份、分辨率、评分、时长、进度** 组合过滤；右上搜索框按标题 / 标签检索。

### 批量操作
在管理和列表视图中可多选媒体，执行 **打标 / 评分 / 移动 / 模板化改名 / 导出**。
改名片名模板示例：`{title} ({year})`、`{series} S{season}E{episode}`。

### 回收站
删除的媒体进入回收站（软删除），可一键恢复或永久清理；删除时有 **10 秒撤销** 倒计时。

## 4. 播放与整理

- **打开播放器**：在媒体库 / 资源库双击任意媒体。
- **手势与快捷键**：快进 / 后退、倍速调节；**倍速与音量、字幕轨** 会按媒体记忆，下次打开自动恢复。
- **片段标记**：播放中打点，将精华片段加入收藏，随时从中跳转。
- **迷你置顶小窗**：把播放器缩小为置顶小窗，边干活边看，进度与主窗口双向同步。
- **继续观看**：自动记录进度与观看状态，在「继续观看」中一键回到上次位置。
- **多源播放**：本地文件 / 网络直链 / HLS 均可播放；HLS 支持清晰度切换与记忆。

## 5. 智能功能

- **智能刮削**：自动从 TMDB 拉取海报与元数据；刮削数据源支持回退。AV 媒体走本地刮削链。
- **AI 标签**：接入 AI 服务后，可对媒体自动打标。
- **系列聚合**：剧集自动聚合成系列视图。
- **智能文件夹**：用规则（标签、年份、评分等）动态生成收藏夹，内容随库自动更新。
- **重复文件检测**：内容哈希 / 同名 / 同大小三种模式，通过向导一键查找并处理重复项。
- **网络媒体**：粘贴 URL 导入；受限内容受「显示限制内容」开关 + 网络源开关双重门控；删除时只移除本地缓存、保留网络源。

## 6. 数据与备份

- **数据位置**：数据库与缓存位于数据目录（默认 `~/.vitoice/`），布局如下：
  - `vitoice.db`：元数据（唯一事实来源）
  - `cache/thumbnails`、`cache/screenshots`：可再生缓存，可安全清理
  - `assets/posters`、`assets/backdrops`：刮削的海报 / 背景图，可重新刮削恢复
  - `backups/`：每日自动备份数据库（自动轮换）
- `cache/` 下内容被清空后会自动重新生成；`assets/` 内容可通过重新刮削恢复。
- 建议定期检查 `backups/`，或将数据目录同步到云端 / NAS。

## 7. 常见问题

**Q：刮削没有匹配到元数据？**
A：先确认已填写 TMDB key；对单条媒体右键手动触发补刮；若标题命中不准，可在设置中调整刮削数据源或回退顺序。

**Q：AV 媒体报道为「受限内容」，如何查看？**
A：需要在设置中打开「显示限制内容」开关；涉及网络源时还需开启网络源开关（双重门控）。

**Q：CPU / 磁盘占用高？**
A：多发生在首次建库或批量生成缩略图期间，属正常；缩略图 / 截图缓存可再生，可清空以释放空间。

**Q：如何迁移到新电脑？**
A：复制完整数据目录（含 `vitoice.db` 与 `assets/`）到新机器的相同位置，或在新机「设置」中指定数据目录后放入数据库文件。
