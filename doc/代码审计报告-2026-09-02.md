## P0 严重

### P0-1 Git 对象库中残留明文 API 密钥（filter-branch 未清理备份引用）

- **证据**：`git for-each-ref` 显示 `refs/original/refs/heads/main` (`88da504`) 与 `refs/original/refs/remotes/origin/main` (`ad87620`) 仍存活，指向重写前的原始提交链。
- `git rev-list refs/original/refs/heads/main --objects` 命中 `generate_image_makabaka.ps1`，blob `13a507c`（4693 字节）第 8 行为明文 API key（完整值已在本报告中掩码，仅保留 `sk-adedd7…53f2` 前后缀便于识别）。
- **当前分支已不含该 blob**（`git rev-list HEAD --objects | grep 13a507c` → 0），但被 ref 引用导致 `git gc` **永不回收**。
- **触发场景**：任何 `git push --all` / `git push --mirror` / 打包 `.git` 目录 / 换机克隆，密钥即重新外泄。
- **矛盾点**：`README.md:65` 声称"仓库不含任何密钥/令牌"，与事实不符。
- **磁盘明文副本仍在**：`G:\Code\vitoice_fin\generate_image_makabaka.ps1:8`（被 `.gitignore:62` 忽略，但文件未删、密钥未吊销）。

### P0-2 SQLite 外键约束全程未开启，所有 `ondelete` 级联形同虚设

- **证据**：`backend/app/database.py:43-46` 仅设置 4 个 pragma（`journal_mode=WAL` / `synchronous=NORMAL` / `busy_timeout` / `wal_autocheckpoint`），**无 `PRAGMA foreign_keys=ON`**。全仓唯一出现 `foreign_keys` 的位置是 `services/reset_data.py:89` 的 `PRAGMA foreign_keys=OFF`。`alembic/env.py` 亦无设置。
- SQLite 每连接默认 `foreign_keys=OFF`，故以下声明在数据库层**永不生效**：`models/media.py:26,67,138`、`series.py:23`、`tag.py:43,48,83,86`、`task.py:42,45`、`library.py`。仅剩 SQLAlchemy ORM 层 cascade 兜底，而 ORM 兜底在 `db.execute(delete(...))` 批量语句下同样不触发。

### P0-3 ffprobe / ffmpeg 子进程超时后泄漏

- **证据**：`backend/app/api/media.py:1560-1614`（ffprobe）与 `1627-1645`（ffmpeg 缩略图）均为
  `await asyncio.wait_for(proc.communicate(), timeout=30)`，超时后 `wait_for` 只取消协程，**不 kill 子进程**；两处均无 `finally: proc.kill()`。
- **对照**：同文件 `1137-1144` 的 `_transcode_stream` 有完整 `finally` + `terminate()` + `kill()`，说明此处是遗漏而非有意。
- **触发**：网络源响应 >30s 时，连续点击"提取网络元数据"累积孤儿 ffprobe（占带宽与句柄）；ffmpeg 解码分支更耗 CPU。

### P0-4 受限内容开关与软删除在 9 处端点被绕过

- **证据**：`_get_media_or_404`（`media.py:142-157`）同时校验 `is_deleted` 与 `get_restricted_library_ids`，但以下端点为裸 `db.get(Media, media_id)`，两项检查全无：
  `subtitles.py:62,78,155`、`segments.py:17,35`、`tags.py:247,298`、`media_urls.py:22,211`、`series.py:242`、`network_sources.py:156`。
- **触发**：关闭"显示受限内容"后，直接请求 `/api/subtitles/media/{id}/subtitles` 仍可读取受限库的字幕内容与 URL 列表。
- **注**：`recycle_bin.py:31` 绕过 `is_deleted` 属设计使然，不计入。
