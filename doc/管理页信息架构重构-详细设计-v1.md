## 0. 背景、目标与非目标

### 目标

1. **消除同一批媒体数据的多套读写实现**：当前"列表 + 筛选 + 批量操作"这条链在 4 处各写了一遍。
2. **让"计数"与"列表"同源**：徽标数字必须等于点进去后的 `total`，不再靠前端凑。
3. **把"问题"从导航条目降级为视图（Saved View）**：导航收敛 10 → 6，同时保留全部能力。
4 把管理页前端代码量从 ≈9338 行压到 ≤6000 行，且不丢功能。

### 非目标（本次明确不做）

- 不改播放器、不做虚拟滚动（M2/P2 已定为"按需评估"）。
- 不合并"媒体页"与"管理页"这两个**页面**——它们是两种工作流（浏览 vs 治理），只合并**底层列表层**。
- 不引入状态管理库、不做组件库抽象。
- 不动 Rust / Tauri / 打包链路。

## 3. 后端契约改造

### 3.1 `GET /media` 新增参数（全部可选，默认 `None` ⇒ 行为不变）

| 参数 | 类型 | 语义 / SQL |
|---|---|---|
| `has_poster` | `bool \| None` | `false` → `poster_path IS NULL AND thumbnail_path IS NULL`；`true` → 反之 |
| `metadata_status` | `'missing' \| 'ignored' \| 'complete' \| None` | `missing` → `metadata_ignored=false AND (poster_path IS NULL OR scrape_data IS NULL)`；`ignored` → `metadata_ignored=true AND (...)`；`complete` → `NOT (...)` |
| `untagged` | `bool \| None` | `true` → `NOT EXISTS (SELECT 1 FROM video_tags WHERE media_id = media.id)` |
| `exclude_network` | `bool \| None` | `true` → `media_type != 'network'` |
| `metadata_ignored` | `bool \| None` | 直接命中列（与 `metadata_status` 二选一，给"已忽略"快捷筛） |

已有可复用：`file_missing`、`exclude_series`（语义 = `series_id IS NULL`）、`source`、`search`、`sort_by/sort_order`。

> **口径去重（已知等价项，实施时注意）**
> - `exclude_series=true` ≡ `has_series=false`（`media.py:410` / `:414`），二者留一个即可。建议保留 `has_series`（可双向），把 `exclude_series` 作为兼容别名。
> - 前端 `buildManageParams` 里的 `source==='missing'` 只是 `file_missing=true` 的前端别名（`lib/manage/filters.ts:59`），服务端不存在该 source 值。
> - `source` 服务端只认 `local / network / offline`；`both` 由 `local`/`network` 同时命中，不要新增取值。

### 3.2 谓词单点化（关键）

新建 **`backend/app/services/media_query.py`**，把"什么算一个问题"定义一次：

```python
"""Shared predicates for media "issue" queries.

Single source of truth: `stats` counts and `/media` filters must never drift.
"""
from sqlalchemy import and_, exists, or_, select

from app.models.enums import MediaType
from app.models.media import Media, VideoTag


def issue_scope() -> list:
    """Rows that are eligible to be reported as an issue."""
    return [
        Media.is_deleted == False,          # noqa: E712
        Media.series_id.is_(None),          # 剧集继承父系列的海报/元数据
        Media.media_type != MediaType.NETWORK,  # 纯网络媒体天生无本地文件/海报
    ]


def pred_missing():
    return Media.file_missing.is_(True)


def pred_no_poster():
    return and_(Media.poster_path.is_(None), Media.thumbnail_path.is_(None))


def pred_metadata_missing():
    return and_(
        Media.metadata_ignored == False,    # noqa: E712
        or_(Media.poster_path.is_(None), Media.scrape_data.is_(None)),
    )


def pred_untagged():
    return ~exists().where(VideoTag.media_id == Media.id)


def pred_problem():
    """Union, not a sum — an item missing both poster and metadata counts once."""
    return or_(pred_missing(), pred_no_poster(), pred_metadata_missing())
```

`/media` 端点内（插在 `# --- Total count ---` 之前，`backend/app/api/media.py:517`）：

```python
if has_poster is not None:
    query = query.where(~pred_no_poster() if has_poster else pred_no_poster())
if metadata_status == "missing":
    query = query.where(pred_metadata_missing())
elif metadata_status == "ignored":
    query = query.where(Media.metadata_ignored == True)  # noqa: E712
elif metadata_status == "complete":
    query = query.where(~pred_metadata_missing(), Media.metadata_ignored == False)
if untagged is True:
    query = query.where(pred_untagged())
if exclude_network is True:
    query = query.where(Media.media_type != MediaType.NETWORK)
```

### 4.2 `MediaQueryState`（两套筛选状态的超集）

```ts
// lib/media/query.ts
export interface MediaQueryState {
  // 范围
  libraryId: string;            // '' = 全部
  dir: string;
  // 内容
  section: ContentSection;      // all | movie | tv | image | audio
  // 分类维度（来自原 FilterState）
  genre: string;
  country: string;
  year: number | null;          // 0 = 未知年份
  resolution: ResolutionFilter;
  duration: DurationFilter;
  ratingMin: number | null;
  // 标签（来自原 ManageFilterState）
  tags: string[];
  tagMatch: 'any' | 'all';
  tagTypeId: number | null;
  // 状态视图（唯一入口，取代 status + source 双参数）
  view: SavedViewId;
  source: '' | 'local' | 'network';   // 保留为叠加维度
  // 文本与排序分页
  q: string;
  sort: MediaSortField;
  order: 'asc' | 'desc';
  page: number;
  pageSize: number;
  // 展示
  display: 'table' | 'grid';
}
```

> 注意：`status`（rated/unrated/favorite/untagged/problem/missing/unmatched）与 `source=missing` 合并进 `view`；`rated/unrated/favorite` 属于"属性筛选"，保留为独立布尔/数值参数（`ratingMin`、`favorite`），**不再占用 view 槽位**——因为它们与问题视图可正交叠加（"无标签 + 已评分"）。

### 4.3 `buildMediaQuery()` 纯函数

```ts
export function buildMediaQuery(s: MediaQueryState): MediaListParams {
  const p: MediaListParams = {
    sort: s.sort,
    order: s.order,
    page: s.page,
    page_size: s.pageSize,
  };
  if (s.libraryId) p.library_id = s.libraryId;
  if (s.dir) p.dir = s.dir;
  if (s.section === 'movie') { p.type = 'video'; p.has_series = false; }
  else if (s.section === 'tv') { p.has_series = true; }
  else if (s.section === 'image') p.type = 'image';
  else if (s.section === 'audio') p.type = 'audio';
  if (s.genre) p.genre = s.genre;
  if (s.country) p.country = s.country;
  if (s.year !== null) p.year = s.year === 0 ? 0 : s.year;
  if (s.ratingMin) p.rating_min = s.ratingMin;
  if (s.tags.length) { p.tags = s.tags; p.tag_match = s.tagMatch; }
  if (s.q) p.q = s.q;
  Object.assign(p, resolutionToParams(s.resolution), durationToParams(s.duration));
  return { ...p, ...viewToParams(s.view) };
}

/** view → 服务端谓词参数；与后端 pred_* 一一对应。 */
export function viewToParams(v: SavedViewId): MediaListParams {
  switch (v) {
    case 'missing':   return { file_missing: true, exclude_series: true, exclude_network: true };
    case 'no_poster': return { has_poster: false,  exclude_series: true, exclude_network: true };
    case 'metadata':  return { metadata_status: 'missing', exclude_series: true };
    case 'ignored':   return { metadata_status: 'ignored' };
    case 'untagged':  return { untagged: true, exclude_series: true, exclude_network: true };
    case 'problem':   return { problem: true, exclude_series: true, exclude_network: true };
    default:          return {};
  }
}
```

> `problem=true` 需要后端也提供同一个并集参数（推荐）：`if problem is True: query = query.where(pred_problem())`。这样"存在问题"永远等于徽标数字。

### 4.5 数据层 `useMediaList`

```ts
// lib/media/useMediaList.svelte.ts
export interface MediaListOptions {
  mode: 'paged' | 'infinite';
  getState: () => MediaQueryState;
}

export function createMediaList(opts: MediaListOptions) {
  let items = $state<Media[]>([]);
  let total = $state(0);
  let loading = $state(false);
  let error = $state<string | null>(null);
  let reqId = 0;

  async function reload(): Promise<void> { /* 自增 reqId + abort 上一次 */ }

  return {
    get items() { return items; },
    get total() { return total; },
    get loading() { return loading; },
    get error() { return error; },
    reload,
    loadMore(): Promise<void> { /* 仅 infinite */ },
  };
}
```

要点：
- `total` **一律取服务端 `total`**，删除 `total = items.length` 这类兜底（D4）。
- 请求竞态沿用现有自增 `reqId` 模式（已被现有代码验证）。
- 滚动恢复：管理页用 `manageFilterStore.scrollTop` 迁到 `MediaQueryState` 之外的 `scrollMemory` 模块；媒体页保持现状。
- **`$effect` 内一律 `untrack()` 包裹 async**（项目铁律 1）。

## 9. 风险与回滚

| 风险 | 缓解 |
|---|---|
| URL 兼容破坏返回现场 | redirect 层保留全部 query；PR4 手测清单覆盖"详情返回" |
| 新旧实现并存期数据不一致 | PR3 灰度期强制对比 total，不一致即阻断 |
| 大组件拆分引入响应式回归 | 严守三条铁律：`$effect` 内 `untrack()`；URL 读取用 `realQueryParam`/`liveQueryParam`；禁 `$page.url.searchParams` |
| 统计口径改动影响别处 | PR1 只**新增**字段，旧字段语义不变；`no_metadata` 口径明确记录"含网络媒体" |
| 单 PR 过大 | 每个 PR ≤ 2 个关注点，PR1/2 先行且互不依赖 UI |

**回滚**：每个 PR 独立可 revert；PR3 之后旧实现仍在，回滚只需把导航切回旧 section。
