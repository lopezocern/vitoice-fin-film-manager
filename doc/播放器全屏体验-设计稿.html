设计说明

设计基调

  • 全屏沉浸：画面是唯一主角，所有控制层半透明 + 毛玻璃叠加其上，鼠标静止 3s 自动隐去（播放中）。
  • 恒定深色：播放器舞台为 #000（真实产品如此），不随应用浅色主题变化，保证观影一致性。
  • 控制层三层折叠：整理带（快捷键唤起，5s 自动隐藏，X 锁定）→ 进度条（常驻）→ 按钮行。层级之间不挤动布局。
  • 设计令牌对齐 app.css：accent #3ed6a4 · amber #f5b942 · danger #fb7185。

现有功能真实呈现（均已实现）

  • 手势：单击播放/暂停；双击三分区（左 -10s / 中 全屏 / 右 +10s）；长按 500ms 2× 快进。
  • 快捷键：Space / J L / ← → / , . / 0-9 / I O / T / A / 1-5 / R / S / C / F / M / X / Esc 分层关闭。
  • 整理带：片段起点/终点、快速打标、AI 打标、评分（hover 五星）、收藏、截图（S 剪贴板 / Shift+S 存文件）、字幕。
  • 进度条：缓冲区、片段彩色锚点、Hover 时间+缩略图预览（后端截图端点）、拖拽 seek（转码流重载降级）。
  • 多源切换：网络媒体多个 source（javgg/vidhide/streamwish…）在控制条切换，36h 签名过期提示。
  • HLS 清晰度菜单（自动/1080p/720p/480p，localStorage 记忆）、速度菜单、字幕轨道菜单、音量 hover 滑块。
  • 片段列表面板（跳转/删除）、片段编辑对话框（命名/起止/8 色板）、快速打标对话框（搜索+分组多选+409 去重）。
  • 状态屏：加载中 / 文件丢失（平台链接→外开）/ 网络源失败（刷新源）/ 受限内容遮罩 / 长按 2× 徽标。

建议优化本稿新增（功能未实现，需确认）

  • ① 图标体系：整理带与控制条由 emoji（⏱🏷🤖📸💬）升级为统一线性 SVG 图标，与全局 lucide 风格一致。
  • ② 快捷键帮助面板：按 ? 或顶栏 ? 按钮呼出，分组列出全部快捷键与手势（当前无此入口）。
  • ③ 顶部信息条：标题右侧增加媒体来源/清晰度徽标（本地/网络、1080p），返回按钮加大热区。
  • ④ 整理带锁定态：X 锁定后整理带常驻并高亮 🔧 按钮为 accent，防止误触隐藏。
  • ⑤ 进度条 Hover 预览：预览卡加时间戳 + 「松开跳转」提示，弱化对截图端点的依赖。
  • ⑥ 网络源行：增加 36h 有效期文案与过期态，降低「源失效黑屏」的困惑（详情页已有刷新源）。
